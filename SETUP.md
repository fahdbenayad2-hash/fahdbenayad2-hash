# Profile setup and maintenance

This repository powers the public profile at https://github.com/fahdbenayad2-hash .

## What updates automatically

The scheduled GitHub Actions workflow regenerates `assets/contributions.svg` and `assets/terminal.svg` daily from GitHub's real contribution calendar and public repository statistics. It also runs on push when generator files change, or can be started manually via **Actions → Refresh GitHub profile graphics → Run workflow**.

It requires only the automatic `GITHUB_TOKEN` and `contents: write` permission. No Personal Access Token is required.

If it fails, open the Actions tab, inspect the logs, verify **Settings → Actions → General → Workflow permissions** is set to **Read and write permissions**, and re-run the workflow.

The generator refuses to show invented activity counts; on data-fetch errors it leaves existing SVGs intact.

## Assets

- `assets/avatar.jpg` — illustrated portrait used for the ASCII terminal panel
- `assets/banner.svg` — custom scalable header
- `assets/contributions.svg` and `assets/terminal.svg` — auto-generated by the workflow

Your round account avatar in GitHub's left sidebar is controlled separately in profile settings.

## Local regeneration

```bash
python -m pip install 'Pillow>=10,<12'
export GH_STATS_TOKEN=...   # optional; improves GraphQL reliability
python scripts/render_stats.py
```
