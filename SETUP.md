# Profile setup and maintenance

This repository powers the public profile at https://github.com/fahdbenayad2-hash .

## What updates automatically

The scheduled GitHub Actions workflow creates `assets/contributions.svg` and `assets/terminal.svg` daily from GitHub's real contribution calendar and repository statistics. It also runs on push when generator files change or can be started manually.

It requires only the automatic `GITHUB_TOKEN` and `contents: write` permission. No Personal Access Token is required.

If it fails, open the Actions tab, inspect the logs, verify `Settings → Actions → General → Workflow permissions` is `Read and write permissions`, and try the workflow again.

The dashboard refuses to show invented activity counts; it leaves existing SVGs intact on data fetch errors.

## Assets

`assets/avatar.jpg` is the illustrated portrait.
`assets/banner.svg` is a custom scalable header.
`assets/contributions.svg` and `assets/terminal.svg` are auto-generated by the workflow.
Your round account avatar in GitHub's left sidebar is controlled separately from profile settings.
